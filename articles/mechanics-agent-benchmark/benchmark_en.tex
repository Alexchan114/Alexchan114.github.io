\section{Why evaluate mechanical decisions?}

The benchmark asks whether an agent can turn physical requirements into defensible regions, loads, discretization and verification, then deliver inspectable artifacts. A completion claim is not solve evidence; a valid tool call is not proof of mechanics. CORE denotes the retained detailed region and SUB a condensed substructure, not a predetermined importance label.

Each task requires independent inputs, deliverables and validators. Held-out variants must not be used for prompt tuning; eight families do not support broad capability rankings.

\subsection{M01: Load, units and equilibrium}

Inspect the stepped axial bar. Determine the correct end constraints and force sign; compute tip displacement, support reaction, segment stress and strain energy. Use the provided independent axial solver tool to obtain execution evidence and verify equilibrium. Report all four results in solution and include the solver artifact ID. Do not claim a 3D Abaqus result.

\subsection{M02: Mechanics-driven mesh allocation}

Import the supplied redistributable solid, choose refinement regions using the specified loads and quantity of interest, generate quadratic tetrahedra and demonstrate mesh sensitivity under the DOF budget. Deliver input decks and complete quality evidence, not screenshots alone.

\subsection{M03: Nonlinear preload and contact}

Construct the prescribed preload-then-insert contact analysis without changing material, friction or contact physics. Extract every specified normal contact channel and audit plasticity, endpoint completion and energy measures.

\subsection{M04: Autonomous substructure partition}

Choose retained CORE regions and condensable SUB regions for the provided connected 1D assembly. Preserve active nonlinear/contact behavior over the whole declared load envelope, not just the baseline frame. Run condensation\_test on your candidate. Your solution must list core\_regions, sub\_regions, retained\_dofs, relative\_tip\_error and artifact\_id. Static accuracy, required interface DOFs and a genuine interior-DOF reduction all matter. Justify the decision. This is a spring-chain mechanics fixture, not an Abaqus substructure benchmark result.

\subsection{M05: Bounded manufacturing variables}

Map geometric shapes, independent plate prelift and terminal X/Y translations to bounded normal amplitudes. Generate samples with explicit scales; verify independent control points, rigid translations, mesh quality and the declared interface strategy.

\subsection{M06: Library reuse and interface integrity}

Select or reject candidate substructure libraries using provenance, retained DOFs, node labels and coordinates. Assemble only a compatible library, complete datacheck and verify actual interface coverage. Matching filenames and enlarged Tie tolerance are not sufficient.

\subsection{M07: Pose failure-boundary search}

At fixed manufacturing amplitudes, choose trials to resolve whole-male initial offset/angle failure boundaries before insertion. Verify terminal contact forces at the declared final displacement. Do not assume global monotonicity or classify solver failure as physical failure.

\subsection{M08: Failure recovery and trusted ranking}

Recover a batch containing numerical, mesh, resource and interruption failures. Preserve successful runs and physical conditions, repair only supported errors, then rank complete contact results with explicit exclusions for missing channels or endpoints.

\section{Mechanics behind the executable fixtures}

\subsection{M01: equilibrium and analytical reference}

The stepped bar uses mm, N and MPa. A direct-stiffness solver produces the artifact; the independent validator uses the analytical series-bar solution, checking displacement, reaction sign, segment stress and strain energy.

\begin{align} u_{\rm tip}&=F\sum_i\frac{L_i}{E_i A_i}, & R&=-F,\\ \sigma_i&=\frac{F}{A_i}, & \mathcal{U}&=\frac12 F u_{\rm tip}.\end{align}

\subsection{M04: active nonlinearity and static condensation}

The task is not to delete every low-stress region. Regions r4 and r6 change stiffness within the load envelope and must retain their active nonlinearity. Linear regions r1--r3 can eliminate interior DOFs 1 and 2 while retaining fixed DOF 0 and interface DOF 3. Implement the following expression through linear solves, not explicit inversion.

\begin{equation}\overline{\mathbf{K}}=\mathbf{K}_{rr}-\mathbf{K}_{ri}\mathbf{K}_{ii}^{-1}\mathbf{K}_{ir}.\end{equation}

The accepted partition reproduces the full bilinear tip response at 1, 5 and 12 N. Incorrectly freezing the whole assembly as linear changes the high-load response. This verifies a 1D mechanics fixture, not industrial Abaqus substructure performance.

\section{Scoring, traces and costs}

Executable fixtures use numerical checks, not an LLM judge. Missing artifacts prevent full credit; incorrect partitions, missing interfaces, fabricated error and zero DOF elimination are scored separately. An all-CORE model may be physically correct but receives no reduction benefit. Full 3D error thresholds and compute budgets require independent calibration before registration.

Every observable request/response, tool call/result, exported Pi session, submission and score is retained in JSONL and readable bilingual appendices, including excluded probes. Unexposed internal prompts or reasoning are not reconstructed. SHA256 identifies artifacts. Evaluated models have no filesystem, shell, arbitrary-code or network tools; this does not claim OS isolation for unrestricted native agents.

Input, cache reads/writes and output tokens are separate; reasoning included in output is not added twice. API invoices are unavailable. Pi SDK zero-cost fields are placeholders, not free usage. Author probes, documentation and figure preparation are excluded from task time and tokens. The proposed 96-run campaign has not started.
